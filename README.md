# Calculus3D — 面向大学生的交互式微积分符号推导与 3D 直观几何工作台

> **GitHub 仓库右侧 About 栏简介（直接复制填入 GitHub Description）**：
> 专为学习过微积分但缺乏实操解题直觉的大学生打造的 iOS 符号微积分与 3D 空间几何可视化工具，支持精确分数/π 符号推导、全自由度 3D 透视/平移/坐标轴拉伸、考场破题直觉引导与 iPhone X 3D Touch 深度交互。

## 项目背景与定位

许多理工科大学生在学习完高等数学或微积分理论课后，面对具体定积分、二重积分、三重积分及空间曲面题目时，往往缺乏**几何空间感**与**考场破题直觉**（例如难以想象旋转体微元圆盘、二重积分柱体切面或隐式球面 $x^2+y^2+z^2=R^2$ 的空间尺度，或疑惑何时使用奇偶对称性、分部积分口诀与极坐标换元）。

**Calculus3D** 将**符号微积分推导引擎**、**考场破题直觉教练**与**全自由度 3D 透视几何视图**融为一体，无需联网、零外部依赖，单文件核心架构即可在 iOS 设备（特别是支持 3D Touch 压感的 iPhone X 等机型）上流畅运行。

## 核心功能亮点

| 功能模块 | 核心能力说明 | 典型教学与解题场景 |
| :--- | :--- | :--- |
| **精确有理分数与 $\pi$ 符号引擎** | 基于连分数逼近（Continued Fractions）与 AST 有理化简，严格遵循输入与过程格式，绝不混用分数与小数 | 输入 `3/4` 原样保留；计算 $\int_0^1 x^2\,dx$ 全程输出原函数 `x³/3 + C`、代入步骤 `1/3 − 0 = 1/3`、结果 `= 1/3`、旋转体体积 `V = π/5`；输入 `x²+y²+z²=100` 直接输出 `V = 4000π/3`、`S = 400π` |
| **全自由度 3D 空间几何视图** | 自研防穿模轨道与自由平移相机系统，支持单指/双指自由移动图像、三档曲面透明透视与坐标轴实时拉伸 | 一键切换 **「平移」** 自由移动图像（不再局限于绕中心点旋转）；开启 **「半透 (52%) / 高透 (25%)」** 直接透过球体看清内部原点 `0` 与红/绿/蓝三轴；自动锁定最小安全视距绝不钻入物体内部；拖动底部滑块实时在 `0.6x ~ 2.8x` 范围拉伸 `+X/−X, +Y/−Y, +Z/−Z` 全区域坐标轴 |
| **iPhone X 3D Touch 压感交互** | 键盘按键与算式显示屏全面支持轻按与深按（Force Touch）双层操控，配合 Taptic Engine 触觉反馈 | 轻按输入主功能（如 `x`、`sin`、`=`），用力深按直接触发右上角二级功能（如 `x²`、`sin⁻¹`、`方程=`）；深按上方纯黑显示屏即刻弹出 2D/3D 几何图像；主屏幕重压图标直达【新手使用说明书】与三类积分工作台 |
| **考场破题直觉与系统设置集成** | 所有辅助开关集成于 iOS 原生【系统设置 -> Calculus3D】，默认关闭破题提示以保持纯净计算器界面 | 开启后自动识别奇函数对称区间秒杀、分部积分「反对幂指三」选 $u$ 口诀、极坐标高斯积分换元等技巧，支持考场答案遮挡自测与 8 道期末经典母题一键载入 |

## 快速上手指南

1. **计算定积分 / 多重积分**：
   - 在顶部切换 `∫ 定积分`、`∬ 二重` 或 `∭ 三重`，点击右上角 `[0,1] ▾` 展开上下限抽屉设置积分区间；
   - 输入被积函数（如 `x²` 或 `3/4*x`），点击右下角橙色 `=` 即可查看精确分数/$\pi$ 结果，并在下方切换查看 `偏导 ∂f`、`推导步骤`、`极限/切面` 与 `实验拟合`。
2. **输入空间隐式曲面并查看 3D 透视图像**：
   - 输入 `x²+y²+z²`，**用力深按右下角橙色 `=` 键**打出方程等号 `=`，再输入 `100` 并轻按 `=`，即刻得出 `球体积 V = 4000π/3`；
   - **用力深按上方黑色算式显示区**弹出 3D 视图：点击右侧 `平移` 可单指任意移动球体位置，点击 `半透/高透/实心` 切换球面透明度以观察内部坐标轴，拖动底部第一行滑块可自由拉伸三维坐标轴范围，拖动第二行滑块可动态移动水平截面或旋转体黄金微元圆盘。
3. **开启考场破题提示**：
   - 打开 iPhone 自带的 **【设置】App -> 滑到底部找到【Calculus3D】**，即可随时开启或关闭「💡 考场破题直觉与避坑提示（默认关）」与「🎯 考场答案遮挡自测模式」。

## 一键隐私脱敏编译与打包

将 `Calculus3DViewController.swift` 与 `build_jailbreak_ipa.sh` 放入 Xcode 工程目录，在终端执行：

```bash
chmod +x build_jailbreak_ipa.sh
./build_jailbreak_ipa.sh
```

脚本会自动完成以下工作：
- **全自动隐私脱敏**：清除工程配置、源码文件头、`xcuserdata` 与编译后 ARM64 Mach-O 二进制文件中的全部本机用户名与绝对路径，统一使用匿名开源 Bundle ID（`org.calculus3d.app`）；
- **注入系统设置与高清图标**：自动生成并注入 `Settings.bundle`、主屏幕 3D Touch 四项快捷入口与高清 `exp` 图标，启用 Swift Whole-Module (`-O`) 全模块编译优化；
- **生成开源防抄袭文件**：自动生成 `.gitignore` 与双语 `LICENSE`。
